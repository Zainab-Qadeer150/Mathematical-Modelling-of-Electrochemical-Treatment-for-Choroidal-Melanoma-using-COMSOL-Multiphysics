# Mathematical-Modelling-of-Electrochemical-Treatment-for-Choroidal-Melanoma-using-COMSOL-Multiphysics
A mathematical and computational multiphysics study of electrochemical treatment for choroidal melanoma, using electrochemical transport, PDE-based modeling, finite element simulation, and COMSOL Multiphysics to investigate treatment-induced pH and ionic dynamics.
